# ANTIGRAVITY MAXIMUM-FORCE BUILD PROMPT

## PROJECT NAME
**Cheap Packages, Premium Feel — Client-Converting Service Landing Page**

## ROLE
You are an elite product designer, conversion strategist, senior frontend engineer, premium brand designer, copywriter, and UX psychologist.

You are building a **visually striking, conversion-focused, premium-feeling landing page** for a solo web/AI service business that targets **small businesses, trades, therapists, service providers, local brands, and solo operators**.

The page must make **affordable packages feel smart, trustworthy, and attractive** — not cheap in a low-quality way. The vibe should be:
- modern
- premium
- confident
- clean
- persuasive
- emotionally reassuring
- highly actionable

The product goal is simple:
**turn cold traffic or direct outreach traffic into warm leads and quote requests.**

This is not a toy project.
This must feel like a real landing page that could immediately be used to get clients.

---

## PRIMARY BUSINESS GOAL
Create a landing page that helps a solo service provider sell:
- modern websites for small businesses
- affordable web packages
- optional AI-enhanced package upgrades
- fast turnaround and simple communication

The landing page must:
1. build trust fast
2. clearly explain the offer
3. make the pricing easy to understand
4. reduce hesitation
5. make the visitor feel “this is exactly what I need”
6. generate contact form submissions and direct messages

---

## HARD DECISIONS — DO NOT DEVIATE

### Framework
Use **React + TypeScript + Vite**.

### Styling
Use **Tailwind CSS**.

### UI Components
Use **shadcn/ui** where useful, but do not overuse it.
Custom styling and composition should dominate.

### Animation
Use **Framer Motion** with tasteful restraint.
Smooth, premium, high-performance motion only.

### Icons
Use **lucide-react**.

### Routing
A single-page landing page is sufficient.
Use section-based navigation and smooth scroll.
Do not build a large multi-page marketing site unless required for a very strong reason.

### Data / Backend
No backend is required for the first version.
Use a local mock contact flow and well-structured form components.
Design the code so a real backend or form handler can be integrated later.

### Language
The final page content must be in **Croatian**.
Code, comments, architecture notes, and prompt structure can be in English.

## REQUIRED PAGE SECTIONS
Implement all of the following sections with strong UX and copy.

### 1. Hero section
Must instantly communicate:
- what is being offered
- for whom
- why it matters
- primary CTA
- secondary CTA

Hero must include:
- strong Croatian headline
- persuasive subheadline
- primary CTA button
- secondary CTA button
- quick trust/value bullets
- premium visual composition

### 2. Problem / pain section
Show that the business understands the visitor.
Examples:
- outdated site
- weak online impression
- hard-to-find contact info
- no clear offer
- losing trust before first message

### 3. Solution / value section
Explain how the service solves the above.
Focus on speed, clarity, simplicity, modern look, and better inquiry flow.

### 4. “Who this is for” section
Make the visitor self-identify.
Use cards or tiles for business categories.

### 5. Packages / pricing section
This is critical.
It must be visually excellent and extremely easy to compare.
Include:
- package names
- who each is for
- key inclusions
- turnaround hint
- clear CTA on each card
- one highlighted “best value” card

### 6. Process section
Make the process feel easy and low-friction.
Recommended flow:
1. inquiry
2. short agreement / scope
3. design and build
4. review
5. launch

### 7. Portfolio / examples section
Even if placeholder data is used, design this section to feel credible and visually strong.
Support future easy replacement with real case studies.

### 8. FAQ section
Handle objections such as:
- How long does it take?
- What do I need to prepare?
- Can I request changes?
- Do you also help with text?
- Can I start with a cheaper package?
- Is hosting/domain included?
- What does the AI package actually mean?

### 9. Final CTA section
Strong emotional close.
Should make sending a message feel like the obvious next step.

### 10. Contact form section
Must feel simple, not exhausting.
Suggested fields:
- name
- business name
- email or phone
- what they need
- desired package
- short message

Add reassuring microcopy.
