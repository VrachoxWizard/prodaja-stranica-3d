## 8. Detailed section-by-section implementation instructions

- Replace generic/placeholder-feeling branding presentation with a stronger, more serious brand treatment

### Hero
This is a major priority.

Improve:
- headline specificity
- subheadline clarity
- visual composition
- immediate trust
- CTA hierarchy
- premium art direction

Hero should communicate:
- this is for Croatian small businesses
- weak websites damage trust and reduce inquiries

- the process is straightforward and affordable

Do not rely only on giant text and glow.
Make the hero feel more art-directed and more strategically convincing.

Consider:

- a more premium content layout
- a better visual anchor than generic ambient glow alone

### Headline / subheadline
Rewrite for:
- clarity

## 9. Visual design system rules

Create or refine a clear design system.

### Typography hierarchy
- stronger headline hierarchy
- more premium heading treatment
- clean body text rhythm
- tighter but readable paragraph widths
- clear distinction between kicker, title, body, label, and microcopy

### Heading style
- bold, sharp, modern, confident
- not overly noisy
- not generic oversized shouting everywhere
- use scale intentionally, not automatically

### Body text rhythm
- readable line length
- clean spacing between paragraphs and labels
- slightly tighter and more professional feel
- optimized for Croatian readability

### Spacing scale
- create consistent vertical rhythm
- but do not make every section feel identically spaced
- use intentional density variation for narrative pacing

### Grid / container rules
- establish clear max-width strategy
- use layout variation between sections
- avoid repetitive “centered heading + centered paragraph + 3 cards” everywhere
- use split layouts where stronger

### Border radius rules
- refine radius usage
- keep it premium and consistent
- avoid random radius values section-to-section

### Shadow / depth rules
- use shadows and depth sparingly and intentionally
- avoid all cards feeling equally elevated
- create differentiated depth levels

### Background / surface treatment
- keep dark premium base
- reduce overreliance on decorative blur
- make surfaces cleaner and more role-specific
- use subtle contrast between section types

### Card styling rules
Create distinct card families for:
- informational content
- proof/results
- package/service cards
- conversion close / high-importance blocks

Do not use one generic card style everywhere.

### Accent color usage
- use gold strategically
- reserve it for emphasis, CTA, selected state, key metrics, and important accents
- avoid making gold the default answer to every styling decision

### Gradient usage
- gradients should be restrained
- no cheap-looking glow spam
- gradients should support focal points, not replace hierarchy

### Visual restraint rules
- premium means controlled
- remove clutter
- reduce decorative noise
- choose fewer but stronger visual moments

### Iconography consistency
- standardize icon sizes, stroke weights, spacing, and container logic
- icons should support clarity, not decorate emptiness

### Section consistency
- consistent enough to feel designed as one system
- differentiated enough that each section has a distinct job and energy

### Premium polish standards
Everything should feel:
- intentional
- aligned
- balanced
- consistent
- expensive in restraint
- not cheap in effects

## 10. Motion and interaction rules

Motion must be tasteful and performance-conscious.

### Rules
- use subtle animation only
- no gimmicky motion
- no excessive floating clutter
- no gratuitous parallax
- no noisy looping animations competing with content

### Preferred motion behavior
- smooth reveal on scroll
- subtle stagger where useful
- refined hover states
- polished focus states
- soft depth shifts
- small translation/opacity changes only where they improve feel

### Buttons
- premium hover states
- clear active states
- visible keyboard focus states
- no tacky hyper-glow

### Cards / surfaces
- gentle hover elevation only where interactive
- non-clickable cards should not pretend to be clickable
- maintain clear affordance logic

### Forms
- clear focus and validation states
- responsive submission feedback
- no ambiguous interaction states

### Motion purpose
Motion should reinforce:
- structure
- clarity
- confidence
- perceived quality

It should not exist just to make the page feel “fancier.”
